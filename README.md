# RADIX RUSH

2進数・10進数・16進数の大きいゲートを選ぶ広告風ランゲーム。

## 遊ぶ

https://billjp.github.io/radix-rush/

## 操作とルール

- 大きい数のゲートをクリック／タップ、または ← →・A/D キーで選択。
- 正解で軍団が増え、不正解・時間切れで半減。0人でゲームオーバー。
- 3連続正解ごとにボーナス。全12問終了時に180人以上でボス撃破。
- 難易度はゆるめ（12秒）・ふつう（8秒）・鬼（4秒）。
- Spaceで開始／一時停止／再開。Escapeで一時停止。
- 効果音の切替、ブラウザ内のベスト記録保存に対応。

## 構成

ビルド不要のHTML・CSS・JavaScript。GitHub Pagesはmainブランチのルートから配信します。

- `index.html` — 画面
- `style.css` — レイアウトと演出
- `game.js` — 問題生成・判定・軍団アニメーション

外部フォントを読み込めない場合もシステムフォントで動作します。
